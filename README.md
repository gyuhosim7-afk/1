# 라스트 서바이버 (Last Survivor)

브라우저에서 바로 돌아가는 배틀로얄 게임입니다. 설치나 빌드 없이 HTML 파일만 열면
실행됩니다. 두 가지 버전이 들어 있습니다.

| 버전 | 실행 파일 | 설명 |
| --- | --- | --- |
| 3D 3인칭 | `3d/index.html` | three.js 기반. 언덕과 마을이 있는 섬, 어깨 너머 시점 |
| 2D 탑다운 | `index.html` | HTML5 Canvas 기반. 위에서 내려다보는 시점 |

3D 버전이 최신이며, 2D 버전은 그대로 남겨 두었습니다.

## 3D 버전 (3d/)

- **지형**: 값 노이즈로 만든 높이맵 섬. 언덕, 해안선, 바다, 절차적으로 배치한 마을 7곳
- **구조물**: 창고, 민가, 헛간, 컨테이너를 조립해 배치하고 지붕 위로 올라갈 수 있습니다
- **시점**: 어깨 너머 3인칭. 우클릭 정조준 시 시야각이 좁아지고 카메라가 붙습니다
- **사격**: 화면 중앙 조준선이 가리키는 지점으로 나가는 히트스캔 방식.
  머리를 맞히면 2.1배 피해, 이동 중에는 탄퍼짐이 커집니다
- **판정**: three.js Raycaster 대신 상자·원기둥·지형에 대한 해석식 판정을 격자로 색인해
  나무 1000그루 환경에서도 봇 30명이 가볍게 돌아갑니다
- **HUD**: 나침반, 미니맵, 전체 지도(Tab), 피격 방향 표시, 킬 로그
- **아이템**: 권총, 기관단총, 산탄총, 돌격소총, 지정사수총, 저격총이 각각 다른 실루엣의
  3D 모델로 떨어지고, 탄약은 탄통, 회복은 적십자 구급상자로 구분됩니다
- **캐릭터**: 관절을 나눠 달리기, 앉기, 점프, 재장전, 치료, 사망 자세를 애니메이션으로
  표현합니다. 총을 들면 두 손으로 받쳐 드는 자세로 바뀝니다
- **연출**: 총구 화염과 순간광, 탄착 먼지, 착지 반동, 질주 시 시야각 확대,
  해와 흐르는 구름, 물결치는 바다

### 조작 (3D)

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| `Shift` | 질주 |
| `Space` | 점프 |
| `C` | 앉기 (탄퍼짐 감소) |
| 마우스 | 시점 |
| 좌클릭 | 사격 |
| 우클릭 | 정조준 |
| `F` / `R` / `Q` | 줍기 / 재장전 / 치료 |
| `Tab` | 전체 지도 |
| `O` | 설정 (마우스 감도) |
| `Esc` | 마우스 잠금 해제 (일시 정지) |

시작 화면과 일시 정지 화면에서 **마우스 감도**, **정조준 감도**, **Y축 반전**을 조절할 수 있고
값은 브라우저에 저장되어 다음에 열 때도 유지됩니다. 시점은 마우스를 움직인 만큼만 돌아가며,
움직임을 멈추면 곧바로 멈춥니다.

줍기는 발밑 4.2m 안의 아이템을 집고, 조준선이 향한 아이템은 9m 까지 집을 수 있습니다.
집을 수 있는 아이템은 크게 표시되고 화면 아래에 이름이 뜹니다.

마우스 잠금을 지원하지 않는 브라우저에서는 화면 가장자리로 시점을 돌리는 방식으로
자동 전환됩니다. 프레임이 낮으면 해상도와 그림자, 안개 거리를 한 단계 자동으로 낮춥니다.

## 2D 버전

HTML5 Canvas와 순수 자바스크립트로만 만든 탑다운 버전입니다.

## 실행 방법

가장 간단한 방법은 `index.html` 을 브라우저로 여는 것입니다. 설치나 빌드가 필요 없습니다.

```bash
# 방법 1: 파일을 그대로 열기
xdg-open index.html      # macOS 는 open index.html

# 방법 2: 간단한 로컬 서버
npx http-server . -p 8080   # http://localhost:8080
```

### 단일 파일로 배포하기

`dist/last-survivor.html` 은 CSS 와 JS 를 모두 품은 한 개짜리 파일입니다. 이 파일만
전달하거나 정적 호스팅에 올리면 그대로 실행됩니다. 소스를 고친 뒤에는 아래 명령으로
다시 만듭니다.

```bash
python3 tools/build-single.py
```

이 명령은 `dist/last-survivor.html`(2D)과 `dist/last-survivor-3d.html`(3D)을 함께 만듭니다.
3D 단일 파일은 three.js 만 CDN 에서 불러오고 나머지는 파일 안에 들어 있습니다.

GitHub Pages 로 공개하려면 저장소 Settings → Pages 에서 브랜치를 선택해 배포한 뒤
`https://<사용자명>.github.io/<저장소명>/` 으로 접속하면 됩니다.

## 규칙

- 30명(설정 가능)이 한 맵에 떨어져 마지막 한 명이 남을 때까지 싸웁니다.
- 시작할 때는 대부분 맨손입니다. 맵에 흩어진 무기, 탄약, 구급킷을 주워 무장하세요.
- 자기장이 단계적으로 좁아집니다. 자기장 밖에서는 시간당 피해를 입고, 단계가
  올라갈수록 피해량이 커집니다.
- AI 생존자들은 플레이어뿐 아니라 서로도 공격합니다. 교전 소리를 피해 다니는 것도 전략입니다.

## 구조

```
3d/index.html      3D 버전 화면 구성과 HUD
3d/css/style.css   3D HUD 스타일
3d/js/config.js    무기, 자기장, 이동 속도 등 밸런스 수치
3d/js/world.js     노이즈 높이맵, 충돌, 레이캐스트
3d/js/scenery.js   지형 메시, 물, 건물, 나무, 바위 생성
3d/js/entities.js  캐릭터 모델과 아이템
3d/js/ai.js        봇 인공지능
3d/js/game.js      씬 구성, 3인칭 카메라, 사격, 자기장, 미니맵
3d/js/main.js      입력(포인터 잠금), HUD, 메인 루프

index.html      2D 버전 화면 구성과 HUD
css/style.css   UI 스타일
js/config.js    맵·무기·자기장 등 밸런스 수치
js/utils.js     수학 유틸리티와 효과음
js/world.js     맵 생성, 충돌·시야 판정
js/entities.js  캐릭터, 총알, 아이템
js/ai.js        봇 인공지능 (탐색·전투·루팅·자기장 회피)
js/game.js      게임 루프, 규칙, 렌더링
js/main.js      입력 처리와 HUD 갱신
```

밸런스를 바꾸고 싶다면 `js/config.js` 의 값만 조정하면 됩니다. 봇 수는 시작 화면에서
4명에서 59명까지 설정할 수 있습니다.
